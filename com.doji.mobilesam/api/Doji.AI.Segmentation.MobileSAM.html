Class MobileSAM

Predictor using MobileSAM models. Call SetImage(Texture) to specify the image you want to generate masks for. After setting an image you can call Predict(float[], float[]) to get the masks. The results will be stored in the Result RenderTexture.

Remarks

The models come from HF Hub (tools.doji.hf-hub). Loading without waiting works in the Editor and for bundled models on Windows, macOS, Linux and iOS. On Android and the Web, or when the models are downloaded at runtime, use CreateAsync(BackendType, IProgress<DownloadProgress>, CancellationToken).
