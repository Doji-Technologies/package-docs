    Class VHACD

    Computes convex decompositions of meshes and makes colliders from them.

    Remarks

    The decomposition runs as Burst jobs on all platforms. On the Web, the jobs use worker threads when the build has multithreading; without it they run on the main thread with the same result.

    • Compute(Mesh, int) and ComputeAsync(Mesh, int): a mesh in, managed hulls out. Then GenerateColliders(ConvexDecomposition, GameObject) or GenerateCollidersAsync(ConvexDecomposition, GameObject).
    • Schedule(NativeArray<float3>, NativeArray<int>, JobHandle) and Schedule(MeshData, int, JobHandle): native input and output for job and DOTS code.

    GenerateColliders(ConvexDecomposition, GameObject)

    GameObject target
    Returns
    Type Description
    List<Collider>
    Remarks

    The result has one convex collider for each hull, in the order of ConvexHulls. A hull that PhysX cannot use (flat or degenerate) gets no collider. Compute(List<Vector3>, List<int>) does not return such hulls. The PhysX bake of the meshes runs as a parallel job on worker threads where the platform has them; this method waits for it.
