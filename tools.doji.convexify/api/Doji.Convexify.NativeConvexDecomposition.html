    Remarks

    All hulls share one point array and one index array. Hulls has the ranges of each hull. The triangle indices of a hull refer to the points of that hull: index 0 is the point at PointStart. The arrays use the allocator that you give to Complete(Allocator). Call Dispose() when you no longer need them.
