Class BuildInfo

This class stores build context that is used for the process of generating an .msi installer.
This includes information about the build binaries of the generated Windows Standalone Player and information about the WiX build process.

Remarks

Among other things this information is used to deal with various limitations of Windows Installer technology. Two of these being, that the overall size of an .msi installer can not be larger than 2GB if you want the source files to be embedded inside the msi as a .cab archive. Also, individual files can not be larger than 2GB in general.

UseCompression

Whether compression should be used. Cabinet files only support sizes up to 2GB. Hence, if the Unity build includes files larger than 2GB, or if the total size of all the binaries is over 2GB we create an uncompressed MSI instead, which puts all the source files next to the .msi as loose files instead of embedding them in the .msi file.
