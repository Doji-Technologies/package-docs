CreateInstallerFromExistingBuild(string)

Creates an .msi installer from a given existing build.

Declaration
public static void CreateInstallerFromExistingBuild(string buildDirectory)
Parameters
Type Name Description
string buildDirectory

The build directory of the Unity build for which to generate an installer.
Remarks

WiX for Unity uses settings specific to a given Unity project (e.g. UpgradeCode or Application.version). It is highly recommended to always create an installer as part of the Unity build pipeline using CreateInstaller(BuildReport) instead. This ensures installers always use the correct settings. If you absolutely must create an installer from existing build artifacts, care must be taken to not accidentally use it on build artifacts whose settings/version doesn't match the current project settings.
